データを最新にする

このページのデータは、このMacの Claude Code のログ（~/.claude/projects）から作っています。自動では更新されません。

ページと同じフォルダでターミナルを開き、次のコマンドを実行してください。そのあとページを開き直すと最新になります。

python3 build_usage.py

集計の対象は Claude Code の使用分だけです。claude.ai のチャットは含まれません。トークン数はキャッシュから読み込んだ分も含みます。
